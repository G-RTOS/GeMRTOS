Why this notice is a separate file
----------------------------------

grtos.vhd is the GeMRTOS controller, delivered ENCRYPTED. The file is opaque
from its first byte and cannot carry a readable header, so the copyright and
licence that apply to it are stated here instead.

Using the encrypted IP
----------------------

Quartus(R) Prime requires a FlexLM licence file (.dat) to use encrypted IP.
That requirement is technical, not commercial: the IP is encrypted so that a
single canonical version stays under the project's control rather than
fragmenting into uncontrolled forks.

  fixed  -- one machine
  float  -- a licence server serving several workstations

The files distributed with GeMRTOS work with any network adapter. A licence
tied to a specific adapter can be issued on request; it is generated from the
MAC address of the machine running the FlexLM server -- the same detail
Altera asks for when issuing licensed Quartus(R) Prime.
